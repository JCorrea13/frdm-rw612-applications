It is required to implement a Provisioning Configuration Script based on the following requirements:
 
1. The script should be implemented as a .NET 10 file-based application
2. The script should enter in discovery mode for "TCP Servers" for a configurable time.
3. The script should show the discoverd services including host, port, service type and name.
4. The script should allow the user to select one of the services and connect to it.
5. After connecting the script should allow to the user to enter text that on "Enter" should be send to the selected service as plain text.
6. After sending the text to the server the script be terminated.
